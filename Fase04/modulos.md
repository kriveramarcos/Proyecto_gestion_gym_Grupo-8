## Descripción de Módulos

### 1. Módulo de Gestión de Socios e Inscripciones
**Acceso:** Botón "Socios" / "Inscripciones"
Este es el módulo central del sistema. Permite administrar el ciclo de vida de los clientes dentro del gimnasio.
* **Registro de Socios:** Formulario para ingresar datos personales (DNI, Nombres, Correo).
* **Nueva Inscripción:** Asignación de una membresía a un socio y cálculo automático de vencimientos.
* **Renovación:** Opción para extender el tiempo de membresía de un socio existente.
* **Pagos:** Registro del estado de pago (Pagado/No Pagado) de las inscripciones.

### 2. Módulo de Gestión de Membresías y Horarios
**Acceso:** Botón "Membresías"
Permite al administrador configurar los productos que ofrece el gimnasio.
* **Catálogo de Membresías:** Creación y edición de tipos de planes (Diario, Mensual, Anual).
* **Precios y Duración:** Configuración de los costos y la vigencia en días/meses para que el sistema realice los cálculos automáticos.

### 3. Módulo de Personal y Asistencia
**Acceso:** Botón "Personal" / "Asistencia"
Orientado al control de los empleados y entrenadores del establecimiento.
* **Registro de Empleados:** Alta de nuevo personal con sus datos de contacto y cargo.
* **Control de Asistencia:** Registro de entrada y salida para el cálculo de horas trabajadas (si aplica).

### 4. Módulo de Administración y Seguridad
**Acceso:** Botón "Mi Perfil" / "Configuración"
Opciones exclusivas para la cuenta del administrador logueado.
* **Datos del Administrador:** Visualización y edición de los datos personales del usuario actual.
* **Cambio de Credenciales:** Rutina de seguridad para actualizar la contraseña de acceso al sistema, con validación de contraseña actual y confirmación.
