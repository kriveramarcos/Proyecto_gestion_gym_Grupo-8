# Requisitos de usuario (orientados a los stakeholders)

## Stakeholders principales:
- **Administrador / Dueño** (usuario principal)
- **Entrenador** (usuario secundario)
- **Socios / Clientes** (usuarios finales)

## Requisitos (lenguaje natural, “qué quiero como usuario”)

### Administrador / Dueño
- Quiero iniciar sesión como administrador para acceder al sistema y proteger la información.
- Quiero registrar y mantener fichas de mis socios (DNI, nombre, contacto, plan) para tener toda su información organizada.
- Quiero crear y administrar planes de membresía (nombre, duración, precio) para asignarlos a los socios.
- Quiero registrar pagos manualmente y que el sistema actualice automáticamente la fecha de vencimiento de las membresías.
- Quiero ver reportes simples (ingresos diarios/mensuales, asistencia y membresías pendientes) para tomar decisiones.
- Quiero controlar el inventario de equipos (registrar máquinas, cambiar estado) para saber qué está disponible o en mantenimiento.
- Quiero llevar el control de asistencia del personal (hora de entrada/salida) para controlar turnos y generar reportes.
- Quiero poder configurar reglas simples (p. ej. política de no-shows) para gestionar reservas y disciplina.
- Quiero que el sistema sea rápido, seguro y accesible desde el navegador del celular.

### Entrenador
- Quiero ver mi horario y los usuarios asignados a mis clases para organizarme.
- Quiero marcar la asistencia de alumnos en mis sesiones y añadir notas o recomendaciones.
- Quiero acceder a información básica de los alumnos asignados (restricciones, alergias) si corresponde.

### Socio / Cliente
- Quiero que mi tipo de membresía, fecha de inicio y fin estén visibles si me consultan en recepción.
- Quiero que el sistema permita reservar clases y ver el horario de clases disponible.
- Quiero recibir recordatorios (si se implementa) sobre pagos y reservas.
